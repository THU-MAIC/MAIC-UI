What is a Compiler?

A compiler is a sophisticated software tool that translates source code written in one programming language into another language, typically machine code or bytecode that can be executed by a computer.

Key Functions:

  • Lexical Analysis - Breaking code into tokens
  • Syntax Analysis - Building parse trees
  • Semantic Analysis - Type checking
  • Code Generation - Producing executable code

1. Lexical Analysis

The first phase of compilation

Phase 1

What it does:

  • Scans the source code character by character
  • Groups characters into meaningful units called tokens
  • Removes whitespace and comments
  • Builds a symbol table for identifiers

Example:

// Input:
int x = 42;
// Tokens:
INT, IDENTIFIER(x), ASSIGN, NUMBER(42), SEMICOLON

2. Syntax Analysis

Parsing the token stream

Phase 2

What it does:

  • Validates the syntax of the token sequence
  • Creates a parse tree or abstract syntax tree (AST)
  • Reports syntax errors with meaningful messages
  • Uses grammar rules (often CFG) for validation

Parse Tree Example:

    Assignment
       /        \
  Identifier   Expression
      |            /     \
      x        Number    =
                |
               42

3. Semantic Analysis

Checking meaning and correctness

Phase 3

What it does:

  • Performs type checking
  • Checks for undeclared variables
  • Verifies array bounds and function signatures
  • Annotates AST with type information

Type Checking Example:

// Code:
int a = 10;
string b = "hello";
a = b; // Error: Type mismatch!

4. Intermediate Code Generation

Creating machine-independent code

Phase 4

What it does:

  • Converts AST to intermediate representation
  • Uses three-address code or byte code
  • Makes optimization easier
  • Enables portability across architectures

Three-Address Code:

// Input: a = b + c * d
t1 = c * d
t2 = b + t1
a = t2

5. Code Optimization

Improving code efficiency

Phase 5

Optimization Techniques:

  • Constant folding and propagation
  • Dead code elimination
  • Loop optimization
  • Common subexpression elimination

Optimization Example:

Before:
x = 2 * 3
y = x + 4
After:
x = 6
y = 10

6. Code Generation

Final translation to target code

Phase 6

What it does:

  • Maps IR to target machine language
  • Allocates registers and memory
  • Selects appropriate machine instructions
  • Generates relocatable or absolute code

Assembly Output:

// C: int x = 42;
MOV EAX, 42
MOV [x], EAX
// C: return x;
MOV EAX, [x]
RET
